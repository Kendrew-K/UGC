# UGC Pipeline: Eval Loop Journey
Date: 2026-06-21 · Goal: Fix scraper relevance + run iterative evaluation loop (max 7 turns)

## Problems identified (Turn 0 — diagnosis)

### Bug 1: Job stops after picking a clip
- Root cause: `falUpload()` in `pipeline.ts` hits `https://rest.alpha.fal.ai/storage/upload/initiate`
  — this is an unstable alpha subdomain. Should be `https://rest.fal.run/storage/upload/initiate`
- Effect: `swapping` step fails silently, job shows "failed" with a fal upload error

### Bug 2: Scraper not gender-aware
- Root cause: `classifier.ts` prompt returns generic keywords like `["fashion", "outfit", "OOTD"]`
  No gender, no content style, no instruction to avoid multi-outfit compilations
- Effect: scraping a men's jacket returns mixed female/compilation/irrelevant videos

### Bug 3: No relevance filter
- Root cause: All scraped candidates shown to user with no scoring
  User has no way to tell which ones are actually relevant
- Effect: user picks a video that doesn't match the product

## Design decisions

### Classification upgrade
Add `gender`, `contentStyle`, `searchQueries` to Classification:
- `gender: 'male' | 'female' | 'unisex'`
- `contentStyle: 'solo-outfit' | 'beauty-routine' | 'product-demo' | 'lifestyle'`
- `searchQueries: string[]` — 3-5 specific TikTok phrases (e.g. "men fit check leather jacket")

### Candidate metadata upgrade
Add `title`, `hashtags` from Apify response so evaluator can score relevance

### Claude-powered evaluator
New `src/lib/evaluator.ts` — scores each candidate 0-10 for relevance to product
Filters out score < 4, sorts remainder by relevance score × views
Shows score badge in approval UI

### Eval loop
Script `scripts/eval-loop.ts`:
- 4 test scenarios: men's jacket, women's skincare, unisex sneakers, women's dress
- Mock scraper returns realistic mix (relevant + irrelevant + wrong-gender)
- Claude evaluator scores each scenario
- If avg score < 7: adjust keyword strategy, retry (up to 7 turns)
- Documents each turn here

## Schema changes
- `products.gender TEXT`
- `products.search_queries_json TEXT`
Both added via idempotent migration in `getDb()`
